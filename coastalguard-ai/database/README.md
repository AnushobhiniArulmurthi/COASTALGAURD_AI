# CoastalGuard AI — Database Architecture (Planned)

This directory is reserved for database schemas, migration scripts, and seed files for **CoastalGuard AI**.

## Planned Schema Entities

- **Users & Fishermen Profile**: User ID, contact number, preferred language (English / Tamil), home port/harbour, boat registration details.
- **Harbours & Ports**: Geographic coordinates, emergency VHF radio channels, shelter capacity, real-time alert status.
- **Weather & Marine Forecasts**: Sector-wise swell height, wind velocity, wave period, atmospheric pressure, tide timelines.
- **Alerts & Announcements**: Broadcast warnings, risk severity (Low, Moderate, High, Extreme), issuance timestamp, multilingual translations.
- **Vessel Position Reports**: Transponder IDs, last reported coordinates, signal freshness status.

## Note
This is currently a **Frontend Prototype**. Database connection is not yet configured. All data displayed in the frontend prototype is fictional sample data for demonstration.
